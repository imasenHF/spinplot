# SpinPlot — STYLE_GUIDE

更新日期：2026-10-08（Asia/Shanghai）
适用范围：SpinPlot 独立软件界面、图表预览及导出。以下区分**现有实现**与**后续修改必须保留的规则**；实际值以 `index.html` CSS、`src/interface.js`、`src/twod/ui.js`、`src/twod/palettes.js` 和绘图/导出代码为准。本文件不要求将主站的页面布局直接覆盖本工具。

## 1. 产品视觉定位

SpinPlot 保留桌面科学软件式的紧凑工作区：深蓝标题栏、浅灰立体控件、独立参数面板、白色绘图区和可读状态栏。重点是长时间处理科研谱图时的控件辨识度与参数密度，避免为统一主站外观而改成大卡片或双行网页页头。

同一品牌沿用 plastocyanin 共用图标与金色强调；跨站通用标识、链接行为等规则请见[主站风格规范](https://github.com/imasenHF/imasenhf.github.io/blob/main/docs/SITE_STYLE_GUIDE.md)。

## 2. 色彩与字体（现有实现）

| 元素 | 实现值或策略 |
| --- | --- |
| 应用标题栏 | `linear-gradient(90deg, #173f5f, #245b7f 58%, #6f8794)` |
| 标题文字 | 白色 `#fff`；品牌金色 `#b68c37` |
| 主要交互蓝 | `#173f5f`、`#2f6f9f`，作用依具体控件 |
| 工作区灰 | `--win-gray: #d2d0c8`、`--win-mid: #e7e5de` |
| 正文字色与绘图区 | `--text: #20262a`；绘图区白色 |
| 控件界面字体 | `Tahoma, "Microsoft Sans Serif", Arial, sans-serif`；可经 Interface Preferences 调整 |
| 品牌文字 | `Georgia, "Times New Roman", serif`；`plastocyanin.` 常规 17px、`SpinPlot` 14px |
| 数值/日志 | `Courier New` 或指定的等宽字体；坐标读数在当前样式中使用 Consolas |
| 科学图表文字 | 与界面字体单独设置，支持 Plot font、坐标刻度、轴标题、顶部/右侧投影标题、图例及标注字号 |

以上为实现快照，不表示所有绘图配色必须固定。图表风格由用户选定的 Plot style、Color scheme 和局部覆盖决定，默认选择 MATLAB-like 风格。

## 3. 顶部品牌与导航

- 标题栏高度 **31px**，单行展示图标、`plastocyanin.`、分隔符、`SpinPlot` 和版本信息；图标以 24px 白色方形背景呈现，内部资源约 22px。
- 共用图标与 `plastocyanin.` 链接主站。标题栏文字使用白色，品牌 `o` 和终止圆点保留金色。现有链接 hover、active、focus-visible 有下划线，键盘焦点有可见边框。
- 标题栏不改用主站 Workshop / Notebook 的双行品牌结构；不得在页头叠加整站导航。
- 标题栏下保留菜单栏和常用操作工具栏；项目/配置由 File 菜单和既有快捷按钮管理，不重复建立不一致的保存路径。

## 4. 布局与控件

- 桌面区域由左侧参数栏、可拖动分隔条和右侧绘图区组成。默认左栏宽度 **320px**；主绘图区依据剩余宽度填充；侧栏可以收起。
- 左侧保留 **Data / Processing / Subplots / Axes / Style / Export** 六个选项卡；不因一维或二维切换而改变顶层选项卡个数。不可用的局部选项根据数据和显示模式隐藏或禁用。
- 子图区的逻辑顺序：Data → Plot mode → Axes（X/Y/Z）→ g axis → Colors → Legend & labels → Projections（仅二维）→ Annotations → Processing parameters → Advanced layout。下级参数采用缩进和折叠层级，避免重复分隔线。
- Variable scan 是派生的一维曲线，使用独立的 Variable scan settings（扫描轴、统计方式、统计区间及可选功率换算），不显示二维 Top/Right projection 控件。
- 通用输入行将相关参数组成成对/三列布局：标题与距离、`min/max/tick step`、投影计算区间与显示强度区间分别成组；标签换行时输入框基线保持对齐。无关参数不强制挤入同一行。
- 原生复选框统一 **14×14px**、文字同行，`accent-color: #173f5f`；控件有明确选中、禁用及键盘焦点状态。不采用仅靠颜色区分的交互反馈。
- 按钮操作行保留纵向空隙；`Auto Z` 单独置于操作行。参数区域允许必要的紧凑排列，但不得互相遮挡。
- 调色板以分组下拉和色条预览显示，选择状态须清楚；子图、二维 Heatmap/Stack、投影可分别配置颜色。
- 现有 CSS 在 **1100px、760px、420px** 等宽度条件下调整布局/文字；窄侧栏还有容器查询。新控件需检查标签折行、横向溢出、可点击范围和绘图可见性，不把响应式 CSS 的存在当作实际移动端验收。

## 5. 谱图视觉与坐标

- **一维**：支持多曲线、Stack/叠加、坐标网格、图例、标注、ΔB 测距及上下/左右坐标操作；颜色和字号尊重全局设置及子图覆盖。 手动曲线组在至少两条曲线有效时，可生成 Heatmap 或独立 Variable scan；扫描变量控件的标签与输入框须对齐，空单位不显示括号。
- **二维**：保持主热图/Stack 的物理坐标意义；顶部投影位于主图上方，右侧投影位于右方，色标在右侧相邻区域。投影的计算范围与投影显示轴范围分离。顶部与右侧投影标题共用 Style → Typography 中独立的 Projection titles 字号（默认 11 px），不随 Tick labels 变化；右侧标题在空间不足时按可用宽度缩小并换行。
- **坐标与单位**：字段标题应显示真实物理量及单位。时间轴不得误当磁场轴换算 `g`；尚未声明的 delay 单位保留为空，不推测 `ms`、`ns`。二维图可对相应磁场轴设置 `g` 轴；不覆盖其他类型坐标。
- **主绘图区一致性**：同等网格跨度的一维、二维子图须保持一致的主坐标框尺寸；投影、色标、`g` 轴和外侧图例预留附属空间；交互预览与导出共用这套几何规则。
- **画布尺寸**：独立设计尺寸与浏览器工作区。超出可视区的预览按比例缩小；较小图保持设计尺寸并居中。用户设置的比例和尺寸不应在预览缩放时改变。
- **刻度表达**：全局和子图可设置有效数字、普通/科学计数法；必要时使用公共指数标签；避免相邻刻度显示成相同文本。
- **图形忠实性**：屏幕像素取样不修改原始数组和二维投影统计；向量输出保留可表示的数据单元。显示堆叠偏移不得进入定量计算。

## 6. 导出与交互反馈

- 绘图格式提供 PNG / JPEG / WebP / BMP / TIFF / SVG / PDF，导出尺寸与 DPI 以用户设置为准。
- PDF 中不受基础字体支持的 Unicode 文本不能静默变成乱码；现有实现会对不支持的字符报错，含中文的图例/标题宜使用 SVG 并核对导出。
- 保存项目应包含源数据及绘图配置；保存配置不应误宣称含原始数据。载入旧格式若无法兼容须给出明确提示。
- 图表缩放、测距、清空测距标记、重置范围、撤销/重做等功能的模式反馈需与操作结果一致；退出 ΔB 模式应保留已有标记，Clear ΔB 才删除标记。
- 文件加载、处理错误及重要导出动作使用现有日志和状态栏反馈，避免只依赖弹窗。界面装饰不得遮蔽误差和单位信息。

## 7. 修改检查

1. 与 `index.html`、`src/interface.js` 中真实控件和 CSS 对照，不把尚未写入代码的设计写成现有功能。
2. 检查桌面宽屏、1100px 附近、760px 以下及窄侧栏中的六个选项卡、长标签、复选框和折叠区域。
3. 检查 1D、2D 和混排图的 X/Y/Z/`g` 轴、投影、色标、字体、调色板和导出几何，确认预览与输出一致。
4. 完整科学与跨浏览器验收另按 [PROJECT_CONTEXT.md](../PROJECT_CONTEXT.md) 的范围开展；本规范只记录界面与展示方面的要求。
